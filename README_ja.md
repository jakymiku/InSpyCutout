# InSpyCutout

**InSPyReNetを使った、ローカル動作の軽量な背景切り抜き・簡易マスク編集ツールです。**

[English README](README.md)

InSpyCutout は、AIで前景マスクを作成し、必要な部分だけ手早く修正して透過PNGとして保存することを目的にしています。アニメ・イラスト、AI生成画像、写真風画像などに利用できます。

## 主な機能

- 初回セットアップ後はローカルで画像処理
- InSPyReNet `base` による自動マスク生成
- リアルタイム透過プレビュー
- Alpha Gamma / Mask Offset / Mask Blur / Black Threshold / White Threshold の調整
- 白・黒ブラシでマスクを直接編集
- ブラシサイズ変更、Undo / Redo
- マウスホイールでズーム、複数の方法で移動
- マスクと透過プレビューのズーム / 移動 / フィット同期をON/OFF可能
- 日本語 / English のUI切り替え
- Paint.NET（Microsoft Store版 / デスクトップ版）の自動検出
- 任意の外部マスクエディターを指定可能
- カメラ・スマホ画像のEXIF回転に対応
- 元画像に含まれる既存の透明部分を保持
- サイズの異なる編集済みマスクは自動リサイズせず読み込みを中止
- 元画像ごとに出力フォルダを自動作成

## 推奨動作環境

| 項目 | 推奨 / 補足 |
|---|---|
| OS | 64bit版 Windows 10 / Windows 11 |
| Python | Python 3.11。未導入で `winget` が利用可能な場合はSetupから導入できます。 |
| GPU | **CUDA対応のNVIDIA GPUを推奨**。AIマスク生成が高速になります。 |
| GPUなし / CPUのみ | 動作可能ですが、AIマスク生成はかなり遅くなる場合があります。 |
| AMD / Intel GPU | 現行Windows版ではGPUアクセラレーションを設定していないため、推論はCPUで行います。 |
| メモリ | 16GB以上を推奨 |
| 空き容量 | Python、PyTorch、モデル、ローカルキャッシュ用に数GB以上 |
| インターネット | 初回セットアップとダウンロード時に必要。通常の画像処理はセットアップ後ローカルで行います。 |

NVIDIA GPUを検出した場合、SetupはPyTorch公式のCUDA 12.8ビルドを導入します。比較的新しいNVIDIAドライバーの利用を推奨します。現時点では厳密な最低VRAM容量は設定していません。

## インストール

1. Release ZIPをダウンロードして展開します。
2. **`Setup.bat`** をダブルクリックします。
3. 専用Python環境、必要ライブラリ、モデルの準備が完了するまで待ちます。
4. デスクトップショートカット、または **`Launch_GUI.bat`** から起動します。

専用Python環境は `.venv/`、アプリ専用キャッシュは `cache/` に保存されます。ComfyUIなど、他のPython環境へパッケージをインストールしません。

Setupに失敗した場合は、InSpyCutoutフォルダ内の `setup.log` で詳細なログを確認できます。

## 基本の使い方

1. 元画像を開きます。
2. AIマスクを生成します。
3. 透過プレビューを見ながら Alpha Gamma、Threshold、Blur、Mask Offset を調整します。
4. 残したい部分は白ブラシ、消したい部分は黒ブラシで修正します。
5. 透過画像を保存します。
6. 大きな修正が必要な場合は、マスクを外部エディターへ書き出して編集後に再読込します。

## 操作

| 操作 | キー / マウス |
|---|---|
| 移動モード | `M` |
| ペイントモード | `B` |
| 白 / 黒ブラシ切替 | `X` |
| ブラシサイズ | `[` / `]` またはGUIスライダー |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Y` / `Ctrl+Shift+Z` |
| ズーム | マウスホイール |
| 移動 | 移動モード + 左ドラッグ |
| ペイント中の一時移動 | `Space` を押しながら左ドラッグ |
| いつでも移動 | マウス中ボタンドラッグ |
| 全体表示 | 移動モードでダブルクリック |

ペイントモード中は、編集可能なマスク上でダブルクリックしてもフィットは実行されません。連続クリック時に表示位置が意図せず戻るのを防ぎます。

## マスクの意味

- **白** = 残す / 不透明
- **黒** = 消す / 透明
- **グレー** = 半透明

## 表示同期

**マスク / 透過プレビュー同期** をONにすると、マスクと透過プレビューがズーム・移動・フィット時に同じ画像位置を表示します。ON/OFFはいつでも切り替えでき、選択状態も保存されます。

## 外部マスクエディター

標準は **自動検出（推奨）** です。InSpyCutout は次の順でエディターを探します。

1. デスクトップ版 Paint.NET
2. Microsoft Store版 Paint.NET
3. Paint.NETが見つからない場合は Windows の **「プログラムから開く…」**

Krita、GIMPなどを使う場合は、カスタムEXEとして任意の画像編集ソフトを指定できます。

## 出力

`sample.png` の場合、次のように保存されます。

```text
output/
  sample/
    sample_cutout.png
    sample_mask.png
    sample_raw_mask.png
    sample_edit_mask.png   # 外部編集へ書き出した場合
```

## 設定

UI言語、マスク調整の初期値、ブラシ設定、外部エディター、表示同期などは `config.ini` に保存されます。

通常使う設定の多くはGUIから変更できます。

## 削除・アンインストール

InSpyCutoutを終了し、必要なら `output/` の画像を退避したうえで、展開したInSpyCutoutフォルダを削除してください。アプリ本体、`.venv`、ダウンロードしたモデル、ローカルキャッシュ、設定、出力ファイルはそのフォルダ内に保存されます。

フォルダ外に残る可能性があるものは次の2つです。

- **Python 3.11**：Setupが新規インストールした場合。他で使用していなければWindowsの設定から手動で削除できます。
- **デスクトップショートカット**：アプリフォルダ削除後に残っていた場合は手動で削除してください。
